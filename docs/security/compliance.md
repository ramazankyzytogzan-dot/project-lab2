# Compliance Checklist (ҚР Дербес деректер туралы Заңы)

| № | Сұрақ / Критерий | Мазмұны мен Егжей-тегжейлі Жауабы |
| :-: | :--- | :--- |
| **1** | **Қандай дербес деректер өңделеді?** | Тұтынушылардың телефон нөмірлері, аты-жөні, тапсырыстар тарихы, кассирлердің ИИН мен PIN-кодтары. |
| **2** | **Өңдеудің заңды негізі?** | ҚР ДПЗ 7-бабына сәйкес: Оферта шарты және публичный чек беру кезіндегі тұтынушының келісімі. |
| **3** | **Деректер қайда сақталады?** | ҚР ДПЗ 12-бабының 2-тармағы бойынша: Деректер Астана қ. орналасқан Қазақстандық дата-центрдің (КТК/локальды сервер) PostgreSQL базасында сақталады. |
| **4** | **Кімдердің қолжетімділігі бар?** | Тек авторизациядан өткен кассирге (шектеулі маскаланған түрде) және бас администраторға (толық). |
| **5** | **Сақтау мерзімі қанша?** | Тұтынушылар дерегі — 1 жыл, фискалдық тапсырыс чектер — ҚР Салық кодексіне сәйкес 5 жыл. |
| **6** | **Журнал (Audit Log) жүргізіле ме?** | Иә, `audit_logs` кестесіне кім, қашан, қай деректі өзгерткені/көргені IP-адреспен жазылады. |
| **7** | **ИИ-компонент тәуекелі қандай?** | Бар (сұранысты болжайтын модель). EU AI Act мен ҚР стандарты бойынша **Төмен тәуекел (Low Risk)** категориясына жатады. |
